AI skills for remote hiring teams

Eight skills that help recruiters, founders and hiring managers plan a role, run fair remote interviews, write to candidates and onboard new hires. Built from 150+ cross-border hires, mostly in Pakistan for teams in the US, UK and Gulf.

AI drafts, humans decide

These skills draft, structure and summarise. They never score, rank, shortlist or reject real people. A hiring decision changes someone's life, so it needs a person who can explain it.

The skills will

  • Turn messy notes into a one-page role brief
  • Build a scorecard for your panel to use
  • Organise interview notes into evidence per competency
  • Draft kind, clear candidate emails for you to edit
  • Show where candidates wait in your pipeline

The skills won't

  • Tell you who to hire
  • Fill in a scorecard for a real candidate
  • Recommend hire or no-hire
  • Decide who gets rejected
  • Judge faces, voices or "confidence"

Every skill also leaves out protected characteristics such as age, gender, religion and marital status. It says "values alignment" or "culture add", never "culture fit". And it flags legal topics so you check with a local expert.

The skills

One skill per hiring task. Each one comes with a worked example, tests and a misuse test that checks it refuses to rank or reject people.

Plan the role

role-intake

A one-page role brief: why the role exists, 30/60/90-day success, must-haves, pay, location and timezone overlap.

 scorecard-builder

A weighted scorecard: 4 to 6 competencies, what strong and weak look like, and questions for each.

 job-description-writer

An inclusive remote job post with pay, location and overlap hours at the top.

Interview

remote-interview-kit

A structured interview loop with fair checks for timezone overlap, async writing and remote-readiness.

 interview-debrief

Evidence per competency, where interviewers disagree and open questions. The panel decides.

Communicate, onboard and improve

candidate-emails

Rejection, feedback, update and offer-stage emails that sound human. Every draft is for a person to review.

 remote-onboarding-plan

A first-30-days plan: setup before day one, a buddy, check-ins and a first real deliverable.

 time-to-hire-audit

Paste your pipeline data and see where candidates wait longest, with fixes.

Install

The skills follow the open Agent Skills format, so they work in most AI tools.

Claude Code

Run these inside Claude Code. Claude then picks the right skill from what you type.

/plugin marketplace add osamabinjannat/remote-hiring-skills
/plugin install remote-hiring-skills@remote-hiring-skills

Claude.ai

  1. Download a skill's ZIP from the latest release.
  2. In Settings > Capabilities, turn on Code execution and file creation.
  3. Go to Customize > Skills, click +, then + Create skill, then Upload a skill.
  4. Upload the ZIP and switch the skill on.

Codex, Cursor and other tools

Install with the open-source skills installer:

npx skills add osamabinjannat/remote-hiring-skills

Any AI chat

Open any skill's SKILL.md on GitHub, copy all of it and paste it into ChatGPT, Gemini or any AI chat as your first message. Then give it your task.
