The principle

Built to help you hire. Never to judge.

AI is great at drafting and finding information. It's unsafe at judging people. So every skill drafts, structures and summarises, and leaves the decision with a person who can explain it.

Never ranks or rejects

Ask a skill to pick a candidate and it says no, explains why in a sentence, then hands you something useful instead.

Leaves bias out

Age, gender, religion, nationality, marital status and photos never shape an output. If they're in your notes, the skill says what it removed and why.

Remote by design

Overlap hours in both time zones, clock changes included. Fair checks for written async work and remote-readiness.

Flags the legal parts

Contracts, cross-border pay and right-to-work get a clear Legal check, so you know when to ask a local expert.

Install

Up and running in a minute.

The skills follow the open Agent Skills format, so they work in most AI tools. Pick yours.

Run these two commands inside Claude Code. All eight skills install, and Claude picks the right one from what you type.

Claude Code
/plugin marketplace add osamabinjannat/remote-hiring-skills
/plugin install remote-hiring-skills@remote-hiring-skills

Then try: "Turn my intake notes into a role brief."

  1. Download a skill's ZIP from the latest release.
  2. In Settings > Capabilities, turn on Code execution and file creation.
  3. Go to Customize > Skills, click +, then + Create skill, then Upload a skill.
  4. Upload the ZIP and switch the skill on.

Works on Free, Pro, Max, Team and Enterprise plans.

Use the open-source skills installer. It works with Codex, Cursor and many other AI coding tools.

Terminal
npx skills add osamabinjannat/remote-hiring-skills

Or copy the folders into ~/.agents/skills/ by hand. Codex and Cursor both read it.

  1. Open any skill's SKILL.md on GitHub.
  2. Copy all of it and paste it into ChatGPT, Gemini or any AI chat as your first message.
  3. Then give it your task. Each skill works as a plain prompt.
