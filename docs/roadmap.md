# Roadmap

What we plan to build next. Each idea has an issue on GitHub labelled [`roadmap`](https://github.com/osamabinjannat/remote-hiring-skills/issues?q=is%3Aissue+label%3Aroadmap). Comment there if you want to help or have a better idea.

Ones marked **good first issue** are a good place to start if you haven't contributed before.

| Skill | What it would do | Stage |
|---|---|---|
| `outreach-messages` | Drafts short, personal outreach messages to potential candidates, with the role's pay and overlap hours upfront. **Good first issue** | Source and attract |
| `reference-check-guide` | Builds reference questions tied to the scorecard, a call script and a notes template. **Good first issue** | Decide and offer |
| `take-home-assignment-designer` | Designs a short, fair, realistic take-home task with a time limit, a brief and what good looks like. Flags when it should be paid | Interview |
| `cross-border-offer-checklist` | A checklist for offers across countries: contract type, employer of record, pay currency, notice periods and records to keep. Always carries a legal check | Decide and offer |
| `hiring-process-health-check` | A short self-assessment of a team's whole hiring process against the [playbook](hiring-playbook.md), with the top three fixes. **Good first issue** | Improve |
| Candidate kit | Two skills for candidates: a remote-ready CV review and remote interview prep | Candidate side |

Every new skill follows the same rules as the first eight: **AI drafts, humans decide.**

Want to suggest something else? Open a [new skill idea](https://github.com/osamabinjannat/remote-hiring-skills/issues/new?template=new-skill-idea.yml).
