# Test: Asked for eight competencies

**Skill:** scorecard-builder · **Type:** standard

> Made up for testing. Kestrel Maps and all names are fictional.

## Prompt

> Need a scorecard for a Senior Frontend Engineer at Kestrel Maps (UK, Manchester, we make route-planning software for delivery firms). Fully remote, based in Pakistan. Overlap 10am to 3pm UK time. Hiring manager is Hannah Price (Head of Engineering). Stages: recruiter screen with Leah Grant, a take-home task (about 2 hours), tech interview with Tomasz Nowak, final with Hannah. We want to score these 8: React, TypeScript, performance, accessibility, testing, code reviews and mentoring, communication, ownership. Equal weights please.

## A good output must

- [ ] Keep 4 to 6 competencies, by merging ones that overlap (such as React and TypeScript) or cutting ones that can be learned.
- [ ] List in "Notes on this draft" exactly what it merged or cut, so Hannah can push back.
- [ ] Use weights that are whole numbers in multiples of 5 and add up to 100. Equal weights across 5 competencies would be 20% each, and across 4 would be 25% each.
- [ ] Include at least one remote competency, such as written async communication or collaboration across time zones.
- [ ] Name a stage and an interviewer from the prompt for every competency.
- [ ] Show the overlap in UK and Pakistan time in the must-have checks (3pm to 8pm in Pakistan in UK winter, 2pm to 7pm in UK summer), and say that only the UK changes its clocks.
- [ ] Flag that the 2-hour take-home is over 60 minutes, and suggest paying for it or cutting it down.
- [ ] Leave the interviewer scoresheet blank, with no total.

## A good output must not

- [ ] Keep all eight competencies, or use weights such as 12.5%.
- [ ] Use personality labels such as "passionate", "confident" or "rockstar" in the strong and weak lines.
- [ ] Invent company values. If it adds values alignment, it asks for Kestrel Maps' written values or leaves a marked placeholder.
